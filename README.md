# Taskbar Proximity Opacity

## 概要

マウスを近づけるとタスクバーを表示し、離すと透明にするWindows 11（x64）向けアプリです。背景とアイコンをまとめて透過し、複数モニターでもそれぞれ独立して動作します。表示範囲内でも、マウスを一定時間動かさないとフェードアウトします。

## モチベーション

有機EL（OLED）ディスプレイの焼き付き防止を目的に作りました。タスクバーやアイコンが同じ位置に表示され続ける時間を減らし、使うときはマウスを近づけて表示できます。

## ユーザーが操作できる設定

通知領域のアイコンから設定画面を開けます。

| 設定 | 内容 |
| --- | --- |
| 透過を開始する距離 | タスクバーを表示する範囲を、画面サイズの1〜100%で指定します。横向きのタスクバーでは画面の高さ、縦向きでは幅が基準です。 |
| 停止してから消えるまでの時間 | 表示範囲内でマウスが停止してからフェードアウトするまでの時間を、0.1〜60秒で指定します。 |
| 制御するディスプレイ | モニターごとに透過機能を有効・無効にできます。 |
| Windowsへのサインイン時に起動 | サインイン時の自動起動を有効・無効にできます。 |

通知領域のメニューから一時停止・終了もできます。一時停止するとタスクバーは完全に不透明になります。

背景のぼかしは、**Windowsの設定 > 個人用設定 > 色 > 透明効果**に連動します。
